# Space Design Website

A premium, responsive Next.js website for Space Design.

## Setup

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Production

```bash
npm run build
npm start
```

## Deploy to Vercel

1. Push this project to GitHub, GitLab, or Bitbucket.
2. Import the repository in Vercel.
3. Keep the framework preset as Next.js and deploy.

The enquiry form is frontend-ready. To enable production submissions, connect it to your preferred API route, CRM, email service, or Vercel Serverless Function.

## Content

Company details were sourced from the public Space Design website. Unverified statistics, testimonials, awards, and project imagery should be reviewed before public launch. Photography shown in the prototype is from Unsplash and should be licensed or replaced with approved Space Design photography.
